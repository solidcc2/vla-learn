# 阿里云计算资源

资源选择需要确认“使用什么资源、环境能否运行、怎样计费和释放”。项目配置保存具体账号、地域、规格、镜像与工作空间；价格、库存和驱动默认值需依据当前证据核验。

## 入口与参考

先读目标子项目配置，再看本机帮助。PAI 的工作空间、镜像、资源组优先使用 `pai`；规格、库存、账单及其余产品使用对应 `aliyun` 入口。工具目录列出插件不代表插件已安装。

按问题读取：

- 找工具：[能力域导航](references/capabilities.md)。
- 选规格、查库存：[规格与库存](references/compute-inventory.md)。
- GPU、CUDA、镜像、驱动：[环境兼容性](references/gpu-compatibility.md)。
- 估价、实际用量、结束释放：[计费与释放](references/billing-release.md)。

## 事实核验

1. 用当前账号、目标地域的只读 API 核对资源、可用标记和价格；复用本次任务中仍适用的结果。
2. 用官方文档解释接口字段、计费条件与兼容限制。缺少权限或查询失败时保留证据缺口，不用静态文档证明账号可购买。
3. 规格列表不保证分配成功；ECS 库存和报价不能直接代替 DLC 资源池和报价。

资源比较依据包括候选规格、适用条件、证据来源及未验证项。保留原始查询响应、查询日期及单位，以便核对时效性。
