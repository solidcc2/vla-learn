# 阿里云操作：先选入口，再核验事实

## 入口选择

先读取项目已有配置，确认用户要操作的产品和资源范围，再检查本机工具帮助。用户指定工具时尊重其选择。

- **PAI 日常操作**：优先检查 `pai --help` 及对应子命令；工作空间、镜像、训练提交、状态和日志使用它已有的能力。
- **规格、库存、报价及其他云产品操作**：检查 `aliyun <product> --help`；PAI 专用工具缺少的接口也从这里补充。
- **本机工具未提供的能力**：查官方 API 和文档，判断是版本差异、插件缺失还是能力未覆盖，再选择安装或直接调用接口。工具目录列出插件不等于插件已经安装。

只读当前任务需要的参考：

- 找产品和命令入口：[能力域导航](references/capabilities.md)。
- 选 GPU、查库存或费用：[实例与价格](references/compute-pricing.md)。
- 准备、提交、恢复或查看训练：[PAI 训练](references/pai-training.md)。

## 查询顺序

1. **本地配置与帮助**：确认已有参数和原生功能；不要输出完整凭据配置文件。
2. **当前账号、地域的只读 API**：查询资源、可用性、报价及权限范围。优先复用本次任务已经取得且仍适用的结果。
3. **官方文档**：解释字段、型号、兼容性、计费规则和限制，或补充 API 未返回的信息。用户明确要求搜索时同时遵从其要求。
4. **实际验证**：按任务使用官方预览、必要的环境验证或已获授权的执行。预览成功与运行成功分别报告。

当前账号和地域相关的结论必须有对应查询依据。官网规格表不能证明账号可购买，ECS 报价不能直接作为 DLC 任务报价。查询失败时说明缺少的证据；不要用静态文档替代实时查询后宣称可用。

## 时效性与版本

本技能保存决策方法与检索入口，不冻结 CLI/API 版本、参数全集、价格、库存或镜像列表。能力导航中的命令名仅作检索线索。

执行时核对本机工具帮助和官方文档适用版本；遇到不一致，确认是客户端版本、API 版本或文档更新差异后再行动。不要仅凭文档描述假设本机已有功能，也不要自动升级工具。API 详细描述引用官方外链，需要时读取对应页面，避免复制一份到技能中。

## 实施约束

- 官方单条命令或配置文件能解决的事情直接使用；只有重复的项目逻辑确实需要时才增加脚本。
- 使用已确认的实际配置。重要值无法确认时，先完成不依赖它的工作，再询问缺失信息；示例值不得伪装成实际可执行配置。
- 账号、Bucket、工作空间、镜像版本、资源规格保留在项目配置；本技能只保存方法和入口。
- 用户要求配置、选型或预览不等于授权创建付费任务。已有提交授权则无需重复询问。
- 创建请求超时或返回不明时，先查询是否已创建，避免盲目重试产生重复任务和费用。

## 证据边界

| 证据 | 能说明什么 |
|---|---|
| 本机 `--help` | 当前工具声明支持该入口和参数 |
| 官方 dry-run | 请求能在本地解析、生成；不证明权限、库存或运行环境 |
| 规格列表 | 规格参数及接口返回的可用标记；不保证分配成功 |
| 库存查询 | 查询时刻、指定地域/可用区和计费条件下的库存 |
| 报价查询 | 指定产品、配置、币种和计费条件下的价格 |
| 实际任务结果 | 本次配置在该环境中的运行结果 |

答复只给用户需要的结论和关键依据。报价保留查询时间、单位与条件；未验证的部分明确标注。
