# GPU、驱动与镜像兼容性

核对的是一个组合：GPU 架构、框架二进制构建、镜像 CUDA/cuDNN、宿主机驱动及训练代码使用的功能。

- 读取镜像完整 tag 或 digest、实际框架构建信息和规格的支持驱动列表。镜像里有 CUDA，不代表宿主机驱动满足条件。
- 驱动字段可以是可选项；“支持哪些版本”不等于“缺省选择哪个版本”。默认值没有证据时标记未知，不假设平台按镜像自动选择。
- 用 NVIDIA 对应 CUDA 版本文档核对最低驱动、向后兼容或小版本兼容条件；用框架官方构建说明核对 GPU 架构支持。
- 小版本兼容可能限制新驱动功能和 PTX 即时编译；涉及 torch.compile、自定义 CUDA 扩展时单独核验。不能把最低兼容条件表述为镜像全部功能已验证。
- 显式驱动用于明确环境，不是永远固定某个版本。选择平台支持且满足环境要求的版本；无兼容组合时重新选择镜像或规格。

结论分成“满足文档条件”“请求可解析”“实际运行通过”。实际 GPU、驱动和框架版本分别依据相应输出；任务配置写了驱动版本不等于已在容器读回该版本。运行验证证据应包含实际 GPU、驱动、框架构建信息和所执行的训练功能。

官方入口：[CUDA 兼容性](https://docs.nvidia.com/deploy/cuda-compatibility/)、[PyTorch 版本与构建](https://pytorch.org/get-started/previous-versions/)。具体版本限制按当前文档核对。
