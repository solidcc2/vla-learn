## SimpleCNN基础结构

卷积神经网路，整体可以看成由特征提取网络+分类器网络构成。

以cifar-10 + SimpleCNN为例，输入是3 x 32 x 32的rgb图像。

### 特征提取网络

整个特征提取过程就是多次堆叠`Conv2d + BatchNorm2d + ReLU + MaxPool2d`：
- 让2d图像的每个像素，感知周围的像素(c_in*c_out*3*3的卷积核)
- 归一化保证数值特征稳定
- 引入非线性拟合能力
- 池化，做特征数据压缩

每一个堆叠，都在增加通道数，压缩2d维度的信息表达，多层后，极端情况下，
压缩到1x1, 其实就是将原图像的信息，重编码到一个一维向量去，向量综合了
像素位置，像素周边情况等信息。在后续接入分类器时，相比直接用原图像编码，
计算量大大压缩，位置&周围信息也有保留。

抽象的类比（个人观点），有点类似傅立叶变换，也是一种类似空间特征函数（原图）
到频率特征函数（特征向量/位置信息）的变换,是表达函数/表示空间的映射。

#### Conv2d

conv2d入参是3个rgb通道，32个输出通道，单通道卷积核是3x3, 边缘padding=1,
这样一个通道图像32x32,会在周边padding 1个像素的基础上，以3x3的卷积核，
默认stride=1,去扫描图像，对每一个原图3x3的位置与卷积核对位相乘，
这样卷积输出的维度就是，`(32 + 1*2 -3) / 1 + 1 = 32`， 由于3个输入通道，
卷积核，32个输出通道，就是`32*3*3*3`的权重/卷积核，矩阵输出是`32*32*32`.
此时单个输出通道的大小，没有变化，但是每个像素，都隐含观察了周围8个像素
点的信息。

通常conv2d还有个bias参数，最有通过conv2d后的效果类似

` y = Wx + bias `

如果其后带有正则化步骤，可以看出，bias参数通常可以忽略，
因为会随着均值 & 方差步骤被忽略。

#### BatchNorm2d
入参是通道数，会将原来的`N*C*H*W`, 这里就是`N*32*32*32`, N是batch数量, 
按照每个通道去做数值归一化，对每个C的`NHW`个数值，求平均`mu`, 
和方差`sigma_2`, 然后进行标准化

` x_h = (x - mu) / sqrt(sigma_2 + epsilon) `

再进行一次线性变换，

` y = gama * x_h + beta `

上述 `mu`, `sigma_2`, `gama`, `beta` 都是通道C维度的参数,`gama`&`beta`
会参与训练，每通道独立。
这里epsilon是为了防止除0，而引入的一个小数。

`gama`和`beta`可以随着学习，含有原本的线性变换的含义。

#### relu
激活函数，主要是用于给前述所有的线性计算过程，增加非线性因子，从而让
最终训练的神经网络，有更好的非线性拟合/学习能力。

```
    ReLU(x) = max(0, x)
```

优势是，计算简单，导数也简单就是0，1的阶越函数，通常情况下，对于x=0, 
导数会直接定义为0。

缺点：死亡ReLU, 对于神经元长期输入小于0, 可能始终输出&梯度为0。
此时可以考虑替代为别的激活函数，例如`LeakyReLU`，`GELU`， `SiLU`等。

其中 `LeakyReLU(x) = x (x > 0) , 0.01x (x <= 0)`, 0.01可以设置。

#### MaxPool2d
池化层，用于对特征/信息进行压缩，`MaxPool2d`就是在2维上取最大值。

类似的池化过程，还有均值`AvgPool2d`， 自适应池化主要也是最大 & 
平均2种`AdaptiveAvgPool2d`, `AdaptiveMaxPool2d`。

还有一些使用较少的池化方法，例如：
- `LPPool2d`： p范数池化，就是区域内p次方求和，然后再求1/p次方（开根）。


### 分类器网络

堆叠全连接层，激活层的简单神经网络。中间引入Dropout是为了防止神经网络过拟合
的正则化算子。两个全连接层，是为了便于在中间插入非线性算子ReLU,
得到分类结果前及时引入非线性特征，以获得非线性拟合能力。

#### Flatten

将原有多维度的向量，展开成一维，是原样的内存重解释。

#### Dropout
dropout是一个正则化算子，方式是通过设置一个丢弃概率p, 让数值可能p概率丢弃，
同时保证所有数值的数学期望不变（留存值除以1-p)，本意就是在分类预测过程中，
引入一些随机噪声，让部分值失效，但又不引起整体特征分布的巨大变化。期待模型，
可以在一定的噪声下得到好的分类效果，提高鲁棒性/泛化能力。

类似的其他算子：
- `AlphaDropout`： 配和`SELU`激活函数设计，会缩放&平移，在引入噪声的同时，
尽量保持输入的均值和方差。
