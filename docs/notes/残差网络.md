## 残差网络

### 主要思想
假设要学习的目标函数是`H(x)`, 普通CNN的神经网络函数是`H_(x)`, 
这样的情况下，在随着`x`变化时，`H(x)`和`H_(x)`会同时变化，
训练过程会更收敛，深层神经网络更难训练。

残差网络的思想是，学习`F(x) = H(x)-x`， 这样也就是让目标神经
网络，单向的去随着`x`向常数0跟随。整体会让训练过程更容易收敛。

思想上来说：相当于为CNN网络提供了一些先验知识，认为神经网络需要
跟随的目标，更倾向在0附近，而不是广泛的值域空间。本质上是对值域
做非线性变换。

### 网络结构

**残差块**
常用于浅层resnet(resnet-18/34)

```text
   Conv2d(3x3) -- BN -- ReLU -- Conv2d(3x3) -- BN
x                                                 + -- ReLU -- output
   ----------------------------------------------
```

对于深层

```text
    Conv2d(1x1) -- Conv2d(3x3) -- Conv2d(1x1)
x                                             + -- ReLU
    ----------------------------------------- 

```
注: 这里的conv2d隐含了conv2d+BN+ReLU的3段式，只在最后一层不做额外ReLU

对于通道/HW发生维度变换的场景：
- 残差分支首个conv2d stride=2降采样
- 直通分支引入一个conv 1x1 stride=2来降采样


### 残差网络的优势

1. 按照残差块划分，多个残差块级联， 形成类似逐步递增/优化的结构，
深层神经网络更好训练。

2. 残差 `x+F(x)`的结构，导数就是`1+df/dx`, 这样即使`df/dx`很小，
也依旧有一个梯度传播路径。这条路径在多个残差块级联时，复合函数求导
时，就可以持续传播梯度，极大降低梯度消失的情况，也约束了梯度在1
周围波动，每层都更接近梯度原样传递。防止梯度消失，防止梯度爆炸。

### 引申理解
CNN是对全连接网络，通过结构定义引入了局部位置有相关性的先验知识。
残差网络，通过结构定义引入了值域空间应该更聚集。
都是通过结构，隐含先验知识，让希望表达的信息，在网络的表达空间中，
更易于表达，或者说是输入输出的函数上，更连续，甚至更光滑。
